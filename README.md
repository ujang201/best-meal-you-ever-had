# The Best Meal You Ever Had

A deterministic one-sentence entry for the make.fun bounty
`u-pangg7-the-best-meal-you-ever-had-a3ac0f85`.

`main.ts` writes a single sentence (at most 200 characters) about the best
meal ever had — grandmother's rendang in Padang, beef so soft it fell apart
on warm rice while coconut steam fogged the glasses and she ladled on more
sauce, smiling — to `/output/entry.txt`. No randomness, no clock,
no network, no input: every run produces byte-identical output.

Run it with:

```sh
node main.ts
```

(Or set `OUTPUT_DIR` to write `entry.txt` somewhere else.)
